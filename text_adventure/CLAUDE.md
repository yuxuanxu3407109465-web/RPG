# 封城第七天：项目说明

现代丧尸末世背景的中文文字冒险游戏，开放世界，角色构筑参考 CRPG（辐射式属性 + 技能树）。
两人合作开发，通过 GitHub 同步。运行方式和文件结构见 README.md。

## 开发约定

- **必须兼容 Python 3.9**：macOS 自带的 `/usr/bin/python3` 是 3.9.6。不要用 3.10+ 的写法（`X | None` 类型标注、`match` 语句等），改完用 `/usr/bin/python3 main.py` 测试。
- 不引入第三方库，只用标准库。
- **内容放数据，规则放代码**：地点、物品、NPC、背景、技能、姿态都写在 `data/*.json`；公式集中在 `stats.py`。
- 玩家看到的文字全部用中文；中文指令允许不加空格（如 `拿手电筒`），英文别名要用空格隔开。
- 存档（`saves/`）不进 Git。改存档格式时要兼容旧存档（参考 `Game.cmd_load` 和 `Character.from_dict` 的做法）。
- 技能数据在启动时会做引用检查（`SkillTrees._validate`），新增引用类字段时一并加检查。

## 已确定的设计

### 角色创建
名字、性别（可自定义）、年龄、身高、样貌（自由填写）、背景（从选项中选）、属性分配、同伴（不带 / 预设 / 自定义）。

### 属性（1~10，5 为普通人）
力量、敏捷、体质、智力、感知、魅力。创建时每项默认 5，共 33 点可重新分配。
衍生数值：负重、近战伤害（力量）；近战精准、闪避、先攻（敏捷）；生命值、生命恢复（体质）；经验倍率、每级技能点（智力）；远程精准、闪避、先攻（感知）；同伴上限（魅力）。
**属性部分的公式暂未最终确定**，计划等其他系统设计完后统一回头检查。

### 技能树
- 花技能点解锁技能；初级技能 1 点，高级技能可能更贵。
- 初始技能点暂定 4（`starting_skill_points`），每级技能点公式暂定，都要等技能树设计完再定。
- **技能效果受所属技能树对应的属性影响。**
- 每棵树至少两条分支，分支只是侧重不同，不限制玩家混着学。
- 技能树：锐器（敏捷）、钝器（力量）、枪械（感知）、武术（体质）、潜行（敏捷）、生存（体质）、搜刮（感知）、交涉（魅力）、医疗（智力）、制造（智力）、灵能（特殊）。
- **灵能无法觉醒**，只有创建角色时选择"灵能者"背景才能解锁。
- 目前每个分支只先设计一两个技能来展示风格：
  - 锐器·长刃（主题：姿态）：长刃姿态（进攻 / 防守 / 决斗，同时只能开一个，手持至少一把长刃即可，支持双持，切换不占行动）；随势斩（无姿态时为普通斩击，各姿态有不同额外效果）
  - 锐器·短刃（主题：流血与弱点）：放血
  - 钝器分支：持盾、双手；交涉分支：说服、威吓（技能尚未设计）
- 除锐器外，其他树里的"入门 / 进阶"都是**占位技能**，等设计后替换。

### 战斗系统（尚未实现，以下是已确定的要求）
- **行动点**：每回合获得（由敏捷决定），移动、使用技能、使用物品都消耗行动点；没用完的留到下回合，上限为每回合获得量的 2 倍；只在战斗中存在，不能带进战斗。开战第一回合就获得行动点。
- **距离与位置**：近战范围、后撤；移动能力受敏捷和穿戴装备影响。
- 借机攻击、护甲（及无视部分护甲）、缴械、持续状态（如流血：每回合掉血，持续 3 回合）。
- 具体数值（行动点数量、移动花费、护甲无视比例、流血伤害等）尚未确定，实现时先询问，不要自行编造。

### 抛骰
战斗和其他检定使用抛骰系统。D20 还是 D100 尚未决定，`dice.py` 两种都支持，默认值在 `data/rules.json`。检定统一以"成功率 %"调用，大成功 / 大失败各 5%。
