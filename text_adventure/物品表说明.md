# 物品表说明

游戏里所有物品都在 **`data/items.csv`**。用 Excel、WPS、Numbers 打开就能改，不用写代码。
**一行 = 一件物品**，第一行是表头（列名），不要改列名。改完保存，重新启动游戏就生效。

## 怎么保存

- **Excel（Windows / Mac）**：直接 Ctrl+S 保存；如果弹出“另存为”，选 **CSV UTF-8（逗号分隔）**。
  选普通的“CSV（逗号分隔）”也能读（游戏会自动认 GBK 编码），但推荐 UTF-8。
- **WPS**：保存为 CSV，提示“可能丢失格式”选“是”。
- **Numbers（Mac）**：文件 → 导出为 → CSV，文字编码选 UTF-8，覆盖原来的 `items.csv`。
- 不要另存成 `.xlsx`，游戏只读 `.csv`。

## 写错了会怎样

启动游戏时会检查整张表。有错就**不启动**，在启动窗口里列出每一处错误，例如：

```
游戏数据有错，没法启动：
物品表 …/data/items.csv 有 2 处要改：
  第 3 行（撬棍）：“武器类型”填的“长剑”认不出来，可以填：徒手、枪械、轻刃、重刃、钝器
  第 5 行（矿泉水）：ID “flashlight” 和前面的物品重复了
```

“第几行”就是表格左边的行号（第 1 行是表头）。

## 每一列填什么

不用的列**留空**就行。“是 / 否”的列：填“是”表示有，留空表示没有。
多个值（别名、标签、效果）之间用 **顿号 、** 隔开（逗号、分号也行）。

### 所有物品都有

| 列 | 必填 | 说明 | 例子 |
|---|---|---|---|
| ID | ✓ | 英文名，只能用字母、数字、下划线，**不能重复**。地图上摆物品、开局物品都用它，**改了 ID 要同时改那些地方** | `machete` |
| 名称 | ✓ | 游戏里显示的名字 | 开山刀 |
| 别名 |  | 玩家打字时也认的叫法 | 砍刀、刀 |
| 描述 |  | 查看时显示的文字 | 一把厚背开山刀…… |
| 重量 | ✓ | 千克，可以有小数；没重量写 0 | 1.2 |
| 可堆叠 |  | 填“是”：一格最多摞 5 个；填数字：一格最多摞这么多 | 是 |
| 物品标签 |  | 食物、寻常医疗物资（“残忍” perk 用不了寻常医疗物资止血） | 食物 |
| 等阶 |  | 破旧、普通、精良、传说；留空 = 普通。每高一阶：武器精准 +1、伤害 +1，护甲值 +1 | 精良 |

### 武器（填了“武器类型”就是武器）

| 列 | 说明 | 例子 |
|---|---|---|
| 持握 | 单手、双手、主手、副手；留空 = 单手 | 双手 |
| 武器类型 | 重刃、轻刃、钝器、枪械、徒手 | 重刃 |
| 伤害骰 | 写成 `1d8` 这样。参考档位：1d4 匕首、1d6 高暴击单手 / 双手长柄、1d8 寻常单手、1d10 寻常双手 | 1d8 |
| 暴击范围 | 留空按武器类型默认（锐器 19-20，钝器 20）；宽暴击写 18-20 | 18-20 |
| 武器标签 | 长柄、破甲、要害、锋利、背刺、流血、招架、沉重 | 背刺、要害 |
| 代用武器 | 是：本来是工具（撬棍、手电筒），伤害自动降一档（伤害骰必须是 1d4~1d10 中的一档） | 是 |
| 劣质 | 是：精准只按属性 ×1 算 | |
| 盾牌 | 是：这是盾牌（可以不是武器） | |

### 护甲（填了“护甲部位”就是护甲）

| 列 | 说明 | 例子 |
|---|---|---|
| 护甲部位 | 头部、身体、手部、腿部、脚部 | 身体 |
| 护甲类别 | 寻常服装（护甲 0）、轻甲（1~3）、重甲（2~6）；留空 = 寻常服装 | 重甲 |
| 护甲值 | 普通等阶的数值，要在类别允许的范围里 | 6 |
| 行动点惩罚 | 每 1 点 = 每回合行动点 −5%（只有重甲才写） | 3 |
| 视野惩罚 | 视野减少几格 | 2 |

### 背包、饰品、披风

| 列 | 说明 | 例子 |
|---|---|---|
| 穿戴位 | 背包、饰品、披风 | 背包 |
| 减重率 | 只有背包写：背着时身上东西的重量打几折（%） | 20 |

### 能使用的东西（填了“使用效果”就会出现“使用”按钮）

| 列 | 说明 | 例子 |
|---|---|---|
| 使用效果 | 用顿号隔开多条，见下表 | 食物 +30、生命 +1 |
| 使用提示 |  界面上显示的效果简介；留空就直接显示“使用效果”那一格 | |
| 使用描述 | 使用时先显示的一句话 | 你拉开罐头盖…… |
| 用后保留 | 是：用了不消耗（默认用一次就没了） | |

“使用效果”能写的：

| 写法 | 效果 |
|---|---|
| `食物 +30` | 食物条 +30（满 100） |
| `水源 +30` | 水源条 +30（满 100） |
| `生命 +5` / `生命 30%` | 回复 5 点生命 / 回复生命上限的 30% |
| `体力 +20` / `体力 25%` | 回复 20 点体力 / 回复体力上限的 25% |
| `解除 流血` | 解除状态（流血、力竭、中毒） |

## 加一件新物品

1. 在表格最下面加一行，填 ID、名称、重量，再按它是什么填对应的列。
2. 想让它出现在地图上：在 `data/world.json` 对应地点的 `"items"` 里加上它的 ID（这一步暂时还要改 JSON，以后可以再做成表格）。
   想让它**随机生成**，就写到那个地点的 `"random_items"`（`[{"id": "绷带", "min": 1, "max": 4}]`：第一次走进这个地点时掷一次个数）；
   好几个地点共用一份清单时，在 `world.json` 顶层写 `"spawn_pools": {"clinic": [...]}`，地点里写 `"random_pool": [{"name": "clinic", "min": 2, "max": 4}]`。
3. 保存，重新启动游戏。

## 给程序员

读表、转换、检查都在 `item_table.py`；`engine.World` 启动时读 `data/items.csv`，转成和以前 world.json `"items"` 一样的字典，引擎其余部分不变。新增物品字段时：在 `item_table.COLUMNS` 加列、在 `_row_to_item` / `to_rows` 两边都处理、在这份说明里补一行。
