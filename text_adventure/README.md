# 封城第七天

现代丧尸末世背景的文字冒险游戏，开放世界、CRPG 风格的角色构筑。

## 运行

需要 Python 3.9 或更新版本（macOS 自带的 `python3` 就可以），不需要安装任何第三方库。
两个入口共用同一个引擎和同一个存档，随便用哪个都行。

**按钮版（浏览器界面）**

```
python3 webui.py
```

会自动打开浏览器指向 `http://127.0.0.1:8730/`。端口被占用时会自动往后找，
也可以加 `--port 9000` 指定端口、加 `--no-browser` 不自动开浏览器。
**再启动一次不会又开一个标签页**：如果这个游戏已经在跑，脚本会认出它、直接把地址告诉你；
页面还开着（20 秒一次心跳）就什么都不开，页面已经关了才重新打开同一个地址。
想强制再开一个页面加 `--open`，想真的另起一个服务加 `--force`。
界面上点按钮就等于输入对应指令（点“东”＝输入 `走 东`），也可以在最下面的输入框里直接打指令。
Windows 上也可以直接双击 `启动网页版.bat`。**玩的时候这个窗口要一直开着**，关掉窗口服务就停了、
网页会断线（进度存在 `saves/` 里，重新启动后读档就能接着玩）。
界面上也有“退出游戏”按钮（主菜单和游戏里都有），点了会结束这一局并把本地服务一起关掉，
不用再手动去关那个黑窗口。

界面分成六个区域，名字固定：**左侧栏**（角色）、**文字栏**（中间上半：房间栏 / 正文 / 指令输入）、
**移动栏**（中间下半正中：六向九宫格）、**快捷区域1** 和 **快捷区域2**（移动栏左右两块预留位，
暂时留空，两边一样宽）、**右侧栏**（最上面一条紧凑时钟，下面这里 / 背包快捷栏 / 休息 / 存档读档 / 系统）。
区域的划分、代码位置和调尺寸的方法都写在 [界面区域.md](界面区域.md) 里，改界面先看它。
**每次移动花掉的体力也写在文字栏的正文里**（例如“（移动消耗 2 点体力：100 → 98/100，用时 1 分钟）”，
走不通时不消耗体力，也就没有这一句；这句话由引擎生成，控制台版同样能看到）。
背包和技能树一样点按钮展开，右侧常驻 3 格背包快捷栏（点一下就是使用 / 装备 / 查看，背包里点 ★ 可以换）；
休息用滑条选 1 分钟 ~ 8 小时（体力满了也能休息，只是时间照走）；存档是「先选动作、再点槽位」两排按钮，
存档 / 读档 / 清空都走这个流程，槽位里已有存档时会先问一句要不要覆盖。

存档有 3 个槽位（`saves/save1.json` ~ `save3.json`）：控制台里写 `存档 2` / `读档 2` / `清空 2`，
网页上点存档盘上的按钮。老版本的单个存档会在启动时自动搬进 1 号槽（只搬一次）。

**换台电脑 / 给别人玩**

```bash
git clone https://github.com/yuxuanxu3407109465-web/RPG.git
cd RPG/text_adventure
python3 webui.py          # Windows 上是 py -3 webui.py，或者双击 启动网页版.bat
```

只要装了 Python 3.9+ 就能跑，不用装任何库、不用联网。服务只监听本机 `127.0.0.1`，
每个人在自己电脑上跑，存档也在自己电脑上（`saves/` 不进 Git，不会被互相覆盖）。
换了新代码之后拉一下就行：`git pull`。

**文字版（控制台）**

```
python3 main.py
```

进入游戏后输入 `帮助` 查看所有指令。

## 文件说明

| 文件 | 内容 |
|---|---|
| `main.py` | 控制台版入口：开场、角色创建、主循环 |
| `webui.py` | 网页版入口：本地 HTTP 服务，把角色创建的问答搬到网页上 |
| `启动网页版.bat` | Windows 下双击启动网页版 |
| `make_icon.py` | 生成图标 `icon.ico`：纯标准库手写 PNG/ICO 编码，改完配色形状重新运行即可 |
| `icon.ico` | 游戏图标（桌面快捷方式用的就是它），`icon_preview.png` 是预览图 |
| `web/` | 网页界面：`index.html`、`style.css`、`app.js`、`icons.svg`（手写 SVG 图标精灵） |
| `界面区域.md` | 网页版界面的六个区域（左侧栏 / 文字栏 / 移动栏 / 快捷区域1 / 快捷区域2 / 右侧栏）：位置、代码位置、怎么调尺寸 |
| `items.py` | 物品的使用效果（效果写在 `data/world.json` 的 `use` 字段里） |
| `engine.py` | 游戏状态与所有玩家指令 |
| `character.py` | 角色、同伴、角色创建流程、角色卡 |
| `stats.py` | 属性衍生数值、经验与升级的公式 |
| `skills.py` | 技能树：解锁条件、学习、显示 |
| `stances.py` | 姿态（长刃分支） |
| `enemies.py` | 敌人：按模板生成，精英 / 首领加成 |
| `dice.py` | 抛骰与 D20 / D100 检定 |
| `map_view.py` | 文字地图 |
| `data/world.json` | 地点、物品、NPC、对话、地图位置 |
| `data/character_options.json` | 属性、背景、预设同伴、成长数值 |
| `data/enemies.json` | 敌人模板 |
| `data/skill_trees.json` | 技能树、分支、技能、姿态 |

大部分游戏内容都写在 `data/` 里的 JSON 文件中，加地点、物品、技能通常不需要改代码。

设计决定和开发约定见 [CLAUDE.md](CLAUDE.md)。
