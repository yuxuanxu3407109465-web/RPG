# 封城第七天

现代丧尸末世背景的文字冒险游戏，开放世界、CRPG 风格的角色构筑。

## 运行

需要 Python 3.9 或更新版本（macOS 自带的 `python3` 就可以），不需要安装任何第三方库。
两个入口共用同一个引擎和同一个存档，随便用哪个都行。

**按钮版（浏览器界面）**

```
python3 webui.py
```

会自动打开浏览器指向 `http://127.0.0.1:8730/`。端口被占用时会自动往后找，
也可以加 `--port 9000` 指定端口、加 `--no-browser` 不自动开浏览器。
**再启动一次不会又开一个标签页**：如果这个游戏已经在跑，脚本会认出它、直接把地址告诉你；
服务自己知道现在还有几个页面在看（页面 20 秒一次心跳），页面还开着就什么都不开，
页面已经关了才重新打开同一个地址。想强制再开一个页面加 `--open`，想真的另起一个服务加 `--force`。
界面上点按钮就等于输入对应指令（点“东”＝输入 `走 东`），也可以在最下面的输入框里直接打指令。
Windows 上也可以直接双击 `启动网页版.bat`。**玩的时候这个窗口要一直开着**，关掉窗口服务就停了、
网页会断线（进度存在 `saves/` 里，重新启动后读档就能接着玩）。
**关掉网页就等于关掉游戏**：页面关掉之前会跟服务打一声招呼，服务等十几秒确认没有别的页面在看，
就结束这一局、自己退出，那个黑窗口也跟着关掉，不用再手动去关它。界面上也有“退出游戏”按钮
（主菜单和游戏里都有），作用和关网页一样。
**关网页不会替你存档**：内存里这一局是跟着服务一起没的，所以关之前记得点一下「保存」
（存档只在你按保存的时候才会变）。浏览器被强杀、电脑休眠这种来不及打招呼的情况例外：
游戏会先在内存里留半小时等你回来，重新双击就能接着玩。

界面分成六个区域，名字固定：**左侧栏**（角色）、**视图栏**（中间上半：房间栏 + 「场景 / 背包」两个页签，
场景是 16×10 的格子地图，人物真的在里面一格一格走；地图居中，左上角浮着时钟，颜色图例在视图栏最下面一条）、
**移动栏**（中间下半正中：东 / 南 / 西 / 北四个方向的九宫格；上下楼没有按钮，点场景里的楼梯格走过去）、
**快捷区域1**（移动栏左边：装备栏，10 个方框，拖动装备 / 脱下 / 换手）、**快捷区域2**（移动栏右边：
文字记录 + 指令输入，高度固定、消息在里面滚动）、**右侧栏**（背包快捷栏 / 休息 / 存档读档 / 系统，
文字精简过、不用滚动就能看全）。
三块下排面板的标题条一样高。区域的划分、代码位置和调尺寸的方法都写在 [界面区域.md](界面区域.md) 里，改界面先看它。
**每次移动花掉的体力也写在文字栏的正文里**（例如“移动至（第 3 列，第 2 行），体力消耗 2，用时 1 分钟”；
每 10 步才扣一次体力，没凑满的那几步写 0，走不通时不消耗体力、也就没有这一句；
这句话由引擎生成，控制台版同样能看到）。
**地上有东西就直接点场景里那个方块**：弹出「走过去 / 拿取 / 查看」（人物是「走过去 / 说话 / 查看」），不用去右侧栏找按钮。
**点「拿取」或「说话」会自动走过去**，走到跟前才动手（「走过去」只移动、不拾取）；
引擎那边的规矩是**必须站在同一格或相邻一格（斜角也算）**，实在走不到才会提示你东西在第几列第几行；
查看不受限制，可以远程看。
背包点视图栏右上角的「背包」页签打开，占满视图栏：一格一堆、最多摞 5 个（带堆叠词条的物品才会摞），
点物品才弹出查看 / 使用 / 装备 / 拆分 / 堆叠 / 丢弃的菜单（拆分、堆叠都在这里，右侧栏的系统栏里没有了），
底部能翻页；把物品拖到装备方框上＝装备，
拖到同种物品上＝合并成一堆，拖到右侧快捷栏的格子上＝登记。右侧的 3 格快捷栏**要手动登记**，
不会自动拿背包里的东西来填。休息用滑条选 1 分钟 ~ 8 小时（体力满了也能休息，只是时间照走）；
存档是「先选动作、再点槽位」两排按钮，存档 / 读档 / 清空都走这个流程，槽位里已有存档时会先问一句要不要覆盖。
**食物和水源**：左侧栏的绿条和蓝条，随时间下降（食物每小时 −2、水源每小时 −4）。降到 50% / 30% / 10% 会有点饿（渴）、饥饿（口渴）、饿死了（渴死了），体力消耗依次 +25% / +50% / +50%，最后一级每回合还会掉 1 点生命。
**能吃能喝的东西**：肉罐头（食物 +30、生命 +1）、矿泉水（水源 +30）、能量棒（食物 +10、体力 +25%）。
**生命降到 0 就死了**，会弹出“你死了”和死因，可以读档或回主菜单。
便利店里的肉罐头是**第一次进去时随机生成 1~5 个**，反复进出不会再多。
**手电筒是拿在手上的武器**（主手副手都能装），带没带它才是下地下停车场的条件——放背包里也算带着。

存档有 3 个槽位（`saves/save1.json` ~ `save3.json`）：控制台里写 `存档 2` / `读档 2` / `清空 2`，
网页上点存档盘上的按钮。老版本的单个存档会在启动时自动搬进 1 号槽（只搬一次）。

**换台电脑 / 给别人玩**

```bash
git clone https://github.com/yuxuanxu3407109465-web/RPG.git
cd RPG/text_adventure
python3 webui.py          # Windows 上是 py -3 webui.py，或者双击 启动网页版.bat
```

只要装了 Python 3.9+ 就能跑，不用装任何库、不用联网。服务只监听本机 `127.0.0.1`，
每个人在自己电脑上跑，存档也在自己电脑上（`saves/` 不进 Git，不会被互相覆盖）。
换了新代码之后拉一下就行：`git pull`。

**文字版（控制台）**

```
python3 main.py
```

进入游戏后输入 `帮助` 查看所有指令。

## 文件说明

| 文件 | 内容 |
|---|---|
| `main.py` | 控制台版入口：开场、角色创建、主循环 |
| `webui.py` | 网页版入口：本地 HTTP 服务，把角色创建的问答搬到网页上 |
| `启动网页版.bat` | Windows 下双击启动网页版 |
| `make_icon.py` | 生成图标 `icon.ico`：纯标准库手写 PNG/ICO 编码，改完配色形状重新运行即可 |
| `icon.ico` | 游戏图标（桌面快捷方式用的就是它），`icon_preview.png` 是预览图 |
| `web/` | 网页界面：`index.html`、`style.css`、`app.js`、`icons.svg`（手写 SVG 图标精灵） |
| `界面区域.md` | 网页版界面的六个区域（左侧栏 / 视图栏 / 移动栏 / 快捷区域1 / 快捷区域2 / 右侧栏）：位置、代码位置、怎么调尺寸 |
| `items.py` | 物品的使用效果（效果写在 `data/world.json` 的 `use` 字段里） |
| `engine.py` | 游戏状态与所有玩家指令 |
| `character.py` | 角色、同伴、角色创建流程、角色卡 |
| `stats.py` | 属性衍生数值、经验与升级的公式 |
| `skills.py` | 技能树：解锁条件、学习、显示 |
| `stances.py` | 姿态（长刃分支） |
| `enemies.py` | 敌人：按模板生成，精英 / 首领加成 |
| `dice.py` | 抛骰与 D20 / D100 检定 |
| `map_view.py` | 文字地图 |
| `data/world.json` | 地点、物品、NPC、对话、地图位置 |
| `data/character_options.json` | 属性、背景、预设同伴、成长数值 |
| `data/enemies.json` | 敌人模板 |
| `data/skill_trees.json` | 技能树、分支、技能、姿态 |

大部分游戏内容都写在 `data/` 里的 JSON 文件中，加地点、物品、技能通常不需要改代码。

设计决定和开发约定见 [CLAUDE.md](CLAUDE.md)。
